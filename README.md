# Behavioral Password Authentication 

# Overview

This project enhances traditional password authentication by analyzing typing behavior using keystroke dynamics.

# Features

* Keystroke dynamics analysis
* Hybrid authentication (Rule-based + AI)
* One-Class SVM for anomaly detection
* Real-time typing visualization

# Technologies

* Python (Flask)
* HTML, JavaScript
* Scikit-learn
* Chart.js

# Working

1. User registers typing patterns
2. System stores behavior
3. During login, typing is analyzed
4. Authentication decision is made

# AI Model

Uses One-Class SVM to detect anomalies in typing behavior.

# Applications

* Banking systems
* Online exams
* Fraud detection
* Secure login systems
